# 从墨墨导入每日词汇

词库页面选择与「英语」「日语」同级的「墨墨每日词汇」，点击「导入今日词汇」，选择「忘记」「模糊」「记忆（认识）」「熟知」中的一个或多个类型，查看数量后导入。导入按钮仅在墨墨菜单下显示。分类依据是当天第一次反馈，只包含已完成当日学习的词；当天有新词和复习词时会一起导入。其他反馈会单独显示，避免遗漏。

学习日从**北京时间每天 04:00** 开始，凌晨 00:00–03:59 仍属于前一天。仅在确认导入词汇时检查学习日，将旧每日词书合并到「往日词汇」，再保存当前学习日的「今日词汇」。打开页面、切回页面、跨过 04:00 和备份操作都不会触发归档。旧版已有的多本每日词书会在下次导入时一并迁移。

历史合并按拼写去除首尾空格、忽略大小写去重，并合并释义；保留单词练习、错题、章节记录、复习进度和原词书来源。曾被当天筛选移除的旧词条也会保留。合并使用数据库事务，完成后才移除旧词书。当前词书和往日词书可以包含同一个词。

同一学习日重新导入会用当前选择的词表更新今日词书，不会混入之前取消的类型。更新后从第一章开始练习；单词练习、错题以及旧词条释义保留。词表变化时，旧章节完成情况不计入新章节进度。

词书保存在当前浏览器的 IndexedDB，刷新后仍然可用，可通过设置中的学习数据备份迁移。已经导入的词书可以继续练习，不支持从墨墨补导历史日期。

## 本机运行

推荐 Node.js 24.5 或更新版本，尤其是使用 HTTP/HTTPS 代理的环境。

首次使用时，在项目根目录安装依赖：

```sh
npm install
```

启动服务后，在「设置 → 墨墨设置」中填写 Token 并保存，也可以从墨墨词库页面进入设置。保存后立即生效，无需重启。Token 保存在项目根目录的 `.memo-settings.json`，文件权限为仅所有者可读写，已加入 Git 忽略；服务所在目录需可写。接口不会回传 Token，学习数据备份和前端构建也不包含它。

兼容在运行进程的环境中配置 `memo_token`（或 `MAIMEMO_TOKEN`）。界面保存的配置优先于环境变量；在界面清除配置会停用导入，即使原环境变量仍然存在。开发时也可以将环境变量写入被 Git 忽略的 `.env.local`，不要使用 `VITE_` 前缀。

```sh
npm run dev
```

用浏览器打开终端显示的 localhost 地址。开发服务器和 Vite preview 已集成同源导入接口。

生产构建也可使用随项目提供的个人服务：

```sh
npm run build
npm run start:memo
```

默认仅监听 `127.0.0.1:5173`，同时检查来源和主机，供本机个人使用。`PORT` 可调整端口。生产服务读取进程环境，不会自动读取 `.env.local`；Node.js 24 支持使用 `node --env-file=.env.local scripts/serve-memo.cjs` 启动。

构建产物在 `build/`。如果使用 `.env.local` 保存凭证，文件内容如下（将占位内容替换为你的真实凭证）：

```dotenv
memo_token=你的墨墨Token
```

使用该文件启动生产服务：

```sh
node --env-file=.env.local scripts/serve-memo.cjs
```

浏览器打开 `http://127.0.0.1:5173`，在「墨墨设置」保存 Token，然后进入词库的「墨墨每日词汇」菜单导入。凭证只需在运行时配置，构建时不需要。

## 私人远程使用

需要远程访问时，设置 `MEMO_ACCESS_PASSWORD`，再设置 `MEMO_HOST=0.0.0.0`，通过 HTTPS 反向代理访问。浏览器使用 HTTP Basic 登录，用户名固定为 `memo`，密码为你配置的访问密码。个人服务对页面和 API 都进行访问校验；请勿将代理配置为移除该验证。

仅部署 `build/` 到 GitHub Pages 等静态托管不能提供服务端导入接口；需要上述个人服务。静态词库和已经保存在同一站点浏览器中的个人词书仍可使用。

## 数据与异常

- 使用墨墨官方 `POST /study/get_today_items`，请求 `is_finished: true, limit: 1000`；不筛选 `is_new`。
- 从现有本地词库检索释义和音标，继续使用项目原有发音。未匹配词保留拼写并在导入前提示，不保证与墨墨 App 内的释义完全一致。
- 需要在墨墨 App 开启自动同步，并在当天打开 App。凭证过期时在「墨墨设置」更新 Token，立即生效。
- 无符合条件的词、网络失败、数据不完整、返回达到 1000 条或读取过程中跨过 04:00 时，不覆盖已有词书。04:00 前读取的预览需要重新获取才能导入。
- 此接口目前为公测，遵守官方频率限制；页面不会定时请求或自动同步。

## 验证

```sh
npm run test:memo
npm run test:memo:e2e
npx tsc --noEmit
npm run build
```

端到端测试使用本地服务器和模拟响应，不访问个人墨墨数据。默认调用系统 Chromium；如需 Playwright 下载的浏览器，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 为其可执行文件路径。
