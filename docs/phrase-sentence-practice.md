# 短语和句子练习

现有英语词书、墨墨导入条目和自定义词书均支持短语、句子。有后端与纯前端模式使用相同的练习和导入功能。

## 导入自定义内容

在词库选择「自定义词书」，点击「导入短语/句子」，粘贴内容或选择 TXT、TSV、JSON 文件。每行一条英文，可用 Tab 分隔中文释义：

```text
take care of	照顾
Don't give up.	不要放弃。
Could you help me, please?	你能帮帮我吗？
```

释义可以省略。JSON 使用数组，兼容现有词库的 `name`、`trans` 字段，也支持 `text`、`translation`：

```json
[
  { "name": "take care of", "trans": ["照顾"], "contentType": "phrase" },
  { "text": "Thank you", "translation": "谢谢", "contentType": "sentence" }
]
```

`contentType` 可为 `word`、`phrase`、`sentence`。自动识别时保留 JSON 中的类型；没有类型的多词条目根据句尾标点识别为短语或句子。也可以通过界面的内容类型统一指定。

导入前会预览条目、重复项和格式问题；有格式错误时需修正后保存。规范化后的整条文本相同时合并释义，保留大小写和标点差异。首尾空白、重复空白及常见弯引号会统一处理。原始内容保存在词书，练习时显示规范化文本。

可以新建词书，也可以追加到已有自定义词书。更新词表后从第一章开始，已有练习、错题及复习记录保留。自定义词书独立保存，不参与墨墨每日词书的归档。

## 输入与显示

- 短语、句子按单词自然换行，当前字符以光标标记，长文本区域会跟随输入滚动。
- 空格及英文逗号、句号、问号、撇号等标点均需要输入。大小写遵循原有设置。
- 输错时保留之前的正确内容，按 Backspace 删除错误字符后继续；也可以退回修改正确内容。
- Enter 开始或暂停，完成最后一个字符后自动进入下一条。普通单词保留原有的错误重试方式。
- 支持原有释义、默写、循环练习和错题复习。首版自定义内容以英语为主。

## 朗读与统计

短语沿用词典发音，句子使用浏览器语音朗读，读取音效设置中的美音/英音、语速和音量。浏览器没有语音能力时朗读按钮不可用，仍可正常输入练习。

短语和句子章节显示完成条目数、CPM 与 WPM：CPM 为正确输入字符数/分钟，标准 WPM 按 5 字符折算 1 词。退格本身不计输入错误，重新输入的正确字符计入输入量。错误字符需修正后才能继续。

新的短语与句子记录带有统计版本和字符计数，统计页单独显示 CPM 与标准 WPM 趋势；历史单词记录保留原来的统计方式。

## 数据备份

通过「设置 → 数据设置」导出和恢复学习数据，可迁移自定义词书、释义、练习、章节和复习记录。墨墨与自定义词书可以一起备份，两种运行模式之间也可以恢复。
